# Deck View Local

Локальный генератор изображений колод Hearthstone. Вставь код или полный экспорт из игры, выбери язык и получи PNG 3000 × 2344. Поддерживаются количество копий, стоимость создания в пыли, сайдборд и руны. Правый нижний угол оставлен для собственного текста.

## Запуск

Дважды нажми **Start.cmd**. Страница откроется в браузере. Окно запуска можно закрыть: сервер работает в фоне. Повторный запуск использует тот же экземпляр. При изменении модулей запуск обновляет сервер после завершения активной генерации. Адрес записан в `server-url.txt`, обычно это http://127.0.0.1:8787.

Нужен Python 3.12 или новее. Первый запуск создаёт `.venv` и устанавливает зависимости. **Аккаунт Blizzard, Client ID и Client Secret не нужны.** Для ручного запуска: `python -m pip install -r requirements.txt`, затем `python server.py`.

Можно вставить весь экспорт колоды. **Ctrl+Enter** запускает генерацию. PNG сохраняются в `generated/`; кнопка скачивания сохраняет выбранный результат. Карты из разных источников масштабируются до одной области без искажения пропорций. Плашка количества размещена ниже карты и не перекрывает текст или характеристики.

## Локальная библиотека и обновления

В `library/` включены полные JSON-записи на русском и английском: **36 219 записей для каждого языка**, включая героев, токены и модули. Основа — полный HearthstoneJSON build 253932. Добавлены 197 записей из официальной публичной галереи Blizzard, которых ещё нет в этом HSJSON, в том числе все пять отсутствовавших карт Harold Rogue. Все 206 доступных записей нового набора были получены для обоих языков; девять уже присутствовали в HSJSON.

Два сжатых JSON занимают **3 764 237 байт, около 3,6 МиБ** суммарно. Это размер карточных данных, без Python, зависимостей и изображений. Обновлённый снимок сохраняется в `cache/library/`; встроенный остаётся резервной копией.

При запуске и использовании программа проверяет свежесть данных; сетевые проверки выполняются не чаще одного раза в сутки. ETag/Last-Modified позволяют не загружать неизменившийся HSJSON повторно. После изменения карты обновляется её изображение. При отсутствии ID программа дополнительно проверяет свежий HSJSON и запрашивает точный числовой ID в публичной галерее Blizzard, затем сохраняет найденную запись. Неудачные обращения ограничены повтором через 10 минут.

При недоступной сети используется последний исправный снимок. Ошибочный или неполный ответ не заменяет библиотеку. Повторная генерация работает без интернета, если нужные картинки ещё находятся в кэше. Если источники вообще не публикуют запрошенный ID, приложение покажет ошибку вместо подмены другой картой.

Изображения скачиваются только для нужной колоды. Кэш изображений ограничен **100 МиБ**: после завершения всех генераций удаляются самые старые использованные картинки. Готовые PNG в `generated/` автоматически не удаляются.

Интерфейс для будущего дек-трекера описан в [INTEGRATION.md](INTEGRATION.md). Результаты проверок — в [QA.md](QA.md).
